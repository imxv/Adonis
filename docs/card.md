# Adonis · 画中轮回 —— 项目卡

**一句话**：一个人加 AI，两天做出的网页像素射击肉鸽。阿多尼斯一次次死去又重生，每一层都是随机抽到的一种画风。

## 问题

做一款"有画面、有手感、有音效"的游戏，传统上要程序、美术、策划、音效几个角色配合几周。个人开发者往往卡在美术和音效素材上，最后只能做出简陋的原型。

## 用户与场景

午休、下班路上想玩几分钟的人：打开网页就能玩，一局 8–12 分钟，不用安装，不用登录。

## 方案

- **玩法**：元气骑士式地牢（异形房间 + 走廊，进门锁门、清怪开门），加上吸血鬼幸存者式的成长（经验宝石、自动法术、进化、尸潮房），再加上以撒式的层级结构（宝物房、Boss 房、地洞下一层）
- **画面**：480×270 像素画面，整数倍放大；像素光照；所有界面文字都是像素字体
- **零素材**：美术全部由代码生成，音效和音乐运行时合成，不依赖任何外部图片和音频

## 创新点

1. **画风即数据**：8 种画风（森林、冰原、沙漠神殿、熔岩、蒸汽工坊、古堡、东方庭院、文艺复兴宫殿）各是一份数据，贴图、配色、敌人、道具、音乐调式全部从数据现场生成，新增一种画风只需加一份数据
2. **通用加成适配所有武器**：12 把武器共用一套属性，"数量 +1"对手枪是多一发、对电磁枪是多跳一次、对剑是多斩一刀，构筑组合不会失效
3. **神话即机制**：死亡与重生对应肉鸽重开；每次击杀开出一朵银莲花，通关时花开满地牢；最终 Boss 是那头野猪
4. **AI 自动试玩工作流**：Agent 用自动试玩脚本逐帧驱动游戏、自动打完整局、放大检查像素，每轮改动先自测再交给人试玩

## 后续计划

- **AI 宠物进化**：AI 根据本局构筑设计宠物的进化形态和技能，结果经过强度校验后入局
- **每日种子与排行榜**：同一天所有人打同一个种子，比用时和击杀
- **更多画风**：画风是纯数据，可以开放给其他人投稿
- **触屏适配**：双摇杆操作，手机上也能玩
