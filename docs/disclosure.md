## 4. Prompt

参赛者对 Agent 下达的关键指令（原话，按时间顺序）：

1. 我想做个网页可以玩的游戏，希望可以足够吸引人，希望有很强的正反馈，可以参考一下很多游戏的玩法，比如说肉鸽，集卡等等玩法
2. 能不能不要用这些电商主题了啊
3. 射击肉鸽 + 宠物系统，2D 肉鸽游戏，强烈的视觉冲击力，每关地图都足够有特色（文艺复兴、赛璐璐、蒸汽时代等），丰富的攻击方式、适配所有攻击方式的加成、多种敌人与地形、出色的 Boss 战，禁止使用刺耳的老式复古电子游戏音效
4. 游戏设定：鼠标手动瞄准；房间加选门；AI 宠物进化放 P2；每关一种画风，下一关换，画风尽量多且随机
5. Adonis 是这个游戏的名字
6. 画风太简陋了，全部换成像素风格吧，游戏玩法参照元气骑士的感觉，同时要结合吸血鬼幸存者的玩法
7. 不用做成这种完全自由度的，要和以撒的结合一样，有一层层的关卡
8. 文字太糊了，你看下有什么好的方式去处理这个文字
9. 所有的部分全部像素化，包括菜单栏状态栏等等；房间要有元气骑士或以撒的房间感，形状多样，中间以廊道连接
10. 进入下一关之后，地洞会一直出现在屏幕中央（bug 反馈）
11. 参考 ACHROMA：视角放低、镜头跟随瞄准方向轻微抖动、怪物数量缩减、武器种类加多、像素风格再优化
