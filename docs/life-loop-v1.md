## 本轮可玩范围

大厅 → 独立2D钓鱼 → 烹饪或NPC委托 → 花园与单份出征补给 → 主线冒险 → 材料/种子回流。所有副玩法自愿参加，无永久叠加战力。

- 钓鱼：1个钓点、3种鱼；一局约30–90秒，包含抛竿、咬钩时机、收线/张力决策、成功或失败和重试，键鼠与触控均可用。不依赖3D空间或新增美术资产。
- 烹饪：3个配方，消耗鱼和既有花园产物，产出既有单份补给或有明确上限的同等选择。材料不足/容量满不扣原料，说明产出与效果。
- NPC：2位角色、3个一次性委托，显示角色诉求、交付进度与奖励。稳定ID防止重复领取；不做依赖系统时间的假每日任务。
- 画廊：1项真实可见的修复进度，消费有上限的材料，修复前后有可见变化。不是仅显示一个已完成数字。
- 花园：保留现有种植收获，解释鱼/产物/配方的用途和回流去向；资源上限、单槽补给、主线成绩公平性不变。
