# Adonis · 画中轮回

## 一句话

2D 射击肉鸽。阿多尼斯一次次死去，又在不同画家的笔下重生：每一关都是一种随机抽到的艺术画风，最后一关永远是那头撞死他的野猪。

## 世界观映射（AI 提议，待参赛者确认）

| 神话 | 游戏 |
|---|---|
| 阿多尼斯每年死而复生 | 肉鸽的死亡与重开 |
| 美术史上被反复描绘 | 每关随机换一种画风 |
| 撞死他的野猪 | 最终 Boss「宿命野猪」，画风随最后一关而变 |
| 血中开出红色银莲花 | 主角与子弹的标志色是银莲花红；经验掉落是花瓣 |
| 猎人、爱神的鸽子与天鹅 | 宠物：猎犬、白鸽、天鹅 |

## 一局的流程

- 3 关，每关 4 个房间加 1 个 Boss 房，一局约 15 分钟
- 房间是一屏大小的竞技场，清完怪后出现两扇门，门上标着奖励，玩家自己选下一步
- 门的奖励类型：稀有加成、新武器、宠物蛋、回血、精英挑战
- 击杀掉落花瓣经验，升级时三选一

## 操作

WASD 移动，鼠标瞄准，按住左键射击，空格冲刺（冲刺期间无敌），Esc 暂停。

## 核心系统

**攻击方式**：6 种发射方式，所有武器共用一套属性。

| 武器 | 发射方式 |
|---|---|
| 速射 | 单发高速弹 |
| 散射 | 锥形多弹 |
| 光束 | 瞬发直线，穿透 |
| 迫击 | 抛射到准星位置，范围爆炸 |
| 回旋刃 | 飞出后折返，来回都能命中 |
| 链电 | 命中后在敌人之间跳跃 |

**通用加成**：加成只改属性，每种武器按自己的方式解释，所以任何加成都适配任何武器。

| 属性 | 速射 / 散射 | 光束 | 迫击 | 回旋刃 | 链电 |
|---|---|---|---|---|---|
| 数量 | 多发 | 多一道 | 多一枚 | 多一把 | 多跳一次 |
| 范围 | 弹体变大 | 变宽 | 爆炸半径 | 刃变大 | 跳跃距离 |
| 穿透 | 穿透敌人 | 墙面反射 | 留下余烬 | 体积加大 | 分叉 |

**元素与反应**：火（燃烧）、冰（减速，叠满冻结）、电（感电）。

| 反应 | 效果 |
|---|---|
| 火 + 冰 = 蒸发 | 单次伤害翻倍 |
| 电 + 冻结 = 碎裂 | 三倍伤害，并溅出冰晶 |
| 火 + 电 = 过载 | 小范围爆炸 |

**流派标签（P1）**：每张卡带 1–2 个标签（弹幕、暴击、元素、宠物），同标签凑满 3 张、5 张时各解锁一次奖励。

**宠物**：最多 3 只，继承玩家 50% 的伤害加成和元素。

| 宠物 | 作用 |
|---|---|
| 猎犬 | 冲向敌人撕咬 |
| 白鸽 | 远距离吸经验，偶尔回血 |
| 天鹅 | 绕身旋转，挡掉敌方子弹 |

**敌人**：游荡者、冲锋兵（先预警再冲撞）、射手、自爆兵（爆炸会连锁）、盾兵（正面免伤）。精英怪带随机词缀。

**Boss**：

| Boss | 出现位置 | 招式 |
|---|---|---|
| 画中守卫 | 第 1、2 关 | 环形弹幕、黄金角螺旋、扇形狙击、召唤，2 个阶段 |
| 宿命野猪 | 第 3 关 | 预警冲撞、跺地冲击波、召唤小猪；二阶段冲撞会在墙上反弹 |

两个 Boss 的名字和外观都随所在关的画风变化。

## 画风系统

每种画风是一份数据，叫"画风包"，包含：

- 调色板：底色、墨线色、主角色、危险色
- 描边方式、阴影方式
- 背景图案、纹理叠加
- 敌人造型语言
- UI 字体与边框
- 音乐的调式与音色

渲染器读取画风包现场生成贴图，所以新增一种画风只需要加一份数据。每局开始时从画风池里不重复地随机抽 3 种。

调试和录视频时可以用 URL 参数指定：`?styles=renaissance,ukiyoe,steampunk&seed=42`。

## 打击感

- 卡帧：暴击 40ms，精英 80ms；击杀 Boss 时慢动作
- 震屏：按创伤值逐渐衰减
- 敌人受击：白闪、击退、挤压回弹
- 伤害数字：暴击放大，并用主角色显示
- 主角：枪口火光、后坐力、冲刺残影
- 连杀：音效音调逐级升高

## 音效

用 Tone.js 实时合成，不用方波和琶音。打击音由三层叠加：瞬态、低通噪声、低频冲击。总线上挂压缩器和限幅器。每种画风对应一套调式和音色。

## 范围分级

**P0**：
- 移动、射击、冲刺
- 4 种武器、20 张通用加成、3 种元素
- 3 只宠物
- 4 种敌人
- 2 关加 2 个 Boss
- 打击感、音效

**P1**：
- 第 3 关和野猪的完整演出
- 流派羁绊、合体技
- 3 个进化武器
- 图鉴
- UI 随画风换皮

**P2**：
- 第 4 关
- Boss 第三阶段
- AI 宠物进化：AI 根据本局构筑设计进化形态和技能，结果经过强度校验

## 技术

- Phaser 3.90 + TypeScript + Vite，音频用 Tone.js
- 纯静态网页，`npm run build` 后 `dist/` 可以直接部署
