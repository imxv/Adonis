# Adonis · 画中轮回

## 一句话

2D 像素射击肉鸽。阿多尼斯一次次死去，又一次次重生：每一层是一种随机抽到的画风，最后一层永远是那头撞死他的野猪。

## 世界观映射

| 神话 | 游戏 |
|---|---|
| 阿多尼斯每年死而复生 | 肉鸽的死亡与重开 |
| 美术史上被反复描绘 | 每层随机换一种画风 |
| 撞死他的野猪 | 第三层 Boss「宿敌野猪」 |
| 血中开出红色银莲花 | 每次击杀在地上留下一朵银莲花；通关时银莲花开满地牢 |
| 猎人、爱神的鸽子与天鹅 | 宠物：猎犬、白鸽、天鹅 |

## 一局的流程

- 开局可选阿多尼斯、骑士、鲸鱼娘或程序员。鲸鱼娘以社区 DeepSeek 娘的蓝发、头鳍、鲸尾和深蓝白女仆裙为造型参考，拥有站立/行走两帧像素动作，起始潮汐枪，弹匣容量 +20%、换弹时间 -10%。程序员穿红格子衫、戴黑框眼镜和工牌、背双肩包，起始递归键盘（RGB 机械键盘，敲出 `</>` 代码块，命中敌人或撞墙后一分为二成 `{}`，再各分成两个 `01`，每层伤害 ×0.6、射程减半；穿过敌人时两半从它两侧飞过、不再打它，撞墙或木箱时反弹回来），攻击频率 +10%、暴击伤害 +30%。角色随本局存档恢复，暂停头像与武器试用窗使用所选角色。四张角色卡在横屏叠成一手扇形牌，选中的浮到最上；触屏上先点一下翻到最上查看，再点一次选择。
- 3 层地牢，每层 8–12 个房间，一局约 8–12 分钟
- 地牢是元气骑士式：房间有多种形状（矩形、切角、十字、L 形、柱厅、回廊），房间之间用三格宽的走廊相连
- 走进未清理的战斗房，门会关上，打完 2–3 波敌人才开门（以撒式的锁门）。每一波整波同时加载、同一帧现身，这一波全部倒下 1.1 秒后下一波才开始加载；屏幕上方显示「波次 2/3」，每波开始时有「第二波」「最后一波」横幅。每波至少 3 只，人数随层数和房间深度增加
- 尸潮房不再一只只冒出来，而是每隔约 3 秒整包刷一批，越接近结束越密
- 每层有：起点、战斗房、一个尸潮房（坚持 20–28 秒）、一个宝物房（三选一）、Boss 房；打倒 Boss 后出现地洞通往下一层
- 击杀掉落经验宝石，升级时落下升级水晶，靠近按 F 打开成长选项；金色技能/强化箱按 F 翻出三张卡任选其一（进化优先，能和已有法术融合的卡下方标注「可融合/将融合」），钢制武器箱只随机开出一把尚未携带的武器，升起后悬浮在打开的箱子上方，再按 F 拾取
- 升级三选一可以选择"跳过"，什么都不拿（也可以按 Esc）；武器可留在箱子上，取消替换不会消耗或重抽
- 箱子、升级水晶、地面武器和宝物台常显类别或名称，只有附近最近且未被墙挡住的一项显示 F 提示。经验宝石、红心靠近自动吸取；元素护盾水晶缺护甲时靠近自动吸取，每次最多回复 1 格现有护甲，不超过上限，不产生额外护盾。满甲时不吸取、不消耗且不反复提示，缺甲后可再靠近拾取。
- 所有战斗来源的元素水晶共用 3 秒生成冷却，地面最多 3 颗有效水晶，每颗 12 秒后消失；成功回甲共用 2 秒拾取冷却。冷却与寿命随暂停冻结，吸附不刷新寿命，水晶不跨层携带；限制按对局实例计算，武器训练预览不占用主场景配额。只限制水晶掉落和拾取，不改变元素反应与伤害；金色升级水晶不受这些限制。
- 已携带两把武器时，获得新武器可选择任意一栏替换；旧武器带着弹药等状态掉到地上，可按 F 再拾取。
- 非战斗时，在最近且无遮挡的武器旁停留 0.35 秒后，右下角显示 120×97 的紧凑试用窗：独立训练场景复用正式角色、主题地板、怪物素材和完整武器攻击效果，原始像素比例播放，保留伤害、攻速、射程或范围、弹匣四项指标。小窗自动避让角色、附近武器与拾取标签；静音且不改变本局数据、奖励或存档。覆盖地面、武器箱和宝物台的武器，不暂停游戏、不自动拾取。开火、战斗（包含波次间隔和尸潮倒计时）、危险残留、离开范围或打开面板时立即收起并暂停训练场。开箱升起期间不接受重复拾取；未拾取的武器连同打开的箱子写入本层存档。

## 房间结构与机关

- 战斗房内部有对称的掩体墙：方柱、短墙、角墙，四周至少留两格通道；房间中心的十字通道永远畅通，生成后会校验所有地板和门都能走到
- 道具：木箱成堆、爆炸桶（打爆会伤到附近的人，包括玩家）、画风道具（树丛、冰晶、墓碑等）
- 机关：地刺（先冒尖预警，再弹起）、锯片（沿地上的滑槽来回）。只在本房间战斗时启动，清房后收起；机关对敌人同样造成伤害，可以引怪
- 机关出现率随层数递增：第一层约 1/4 的战斗房，第三层约一半
- Boss 房有 4 根掩体方柱：挡子弹、挡守卫的旋转光臂；野猪冲撞撞上柱子会眩晕

## 移动端

移动浏览器支持横竖屏和安全区域。左摇杆提供模拟移动速度，右摇杆持续瞄准/攻击，抬手停止攻击并保留瞄准方向；冲刺、换枪、换弹、双持、交互、暂停使用独立触屏按钮，可同时移动与攻击。竖屏预留底部操作区，菜单使用完整可视高度；后台、取消触摸和旋转会释放输入，后台或失焦时暂停对局。桌面仍使用原键鼠操作。

## 难度

开始冒险时，选择角色后进入横向难度选择页：极乐原野（轻松）、奥林匹斯（标准）、塔尔塔罗斯（挑战）。支持方向键 / A、D、滚轮、拖动和点击两侧卡片切换，确认后开始游戏；返回角色选择会保留刚选的角色。首次默认标准，确认后记住所选难度；继续存档和再次重生沿用本局难度。

难度统一控制敌人数量、敌人和 Boss 血量、机关出现率，三档系数分别为 `0.75 / 0.8 / 0.5`、`1 / 1 / 1`、`1.3 / 1.3 / 1.6`。调试参数 `?diff=easy` / `?diff=hard` 预选对应档位，最终以选择页确认的难度为准。

## 主菜单与系统界面

- 主菜单：继续游戏、开始冒险、排行榜、游戏说明、图鉴、设置。方向键或鼠标选择，回车确认
- 存档：进入新的一层、清完房间、拿到奖励时自动存档（本机浏览器）。继续游戏回到存档那一层，已清的房间保持清空，人物回到最后一个安全房间。死亡或通关后存档清除
- 排行榜：每局结束按得分记录，保留前十名。得分 = 击杀×10 + 深入层数×1000 + 等级×50，通关再加 3000 并按用时加分，困难 ×1.3、简单 ×0.8
- 图鉴：武器、法术、加成、宠物、怪物、Boss、地图（画风与房间类型）、机关与道具，共 8 页 83 条。内容全部由数据表和游戏实际贴图生成，新增内容会自动出现
- 游戏说明：操作、地牢、成长、战斗四页
- 设置：难度、音乐音量、音效音量、光照、屏幕震动、镜头前探、伤害数字，保存在本机。从主菜单或暂停页打开时多一行「新手教程 · 重新开始」
- 新手教程：第一次打开画廊时问一次「开始新手教程 / 跳过，直接游玩」，答案存在本机（`adonis.tutorial.v1`），中途关掉页面下次会再问。教程分两段：
  - 画廊导览（4 步）：走动 → 走到左翼生活区 → 走到右翼旅程与收藏 → 走进「画中轮回」。当前目标的牌子发光，不在画面里时屏幕边缘有箭头。导览中其他入口先不开放
  - 实战教学（10 步）：移动、瞄准射击、冲刺、清理战斗房、经验与升级水晶、技能宝箱、武器箱、换枪、双持、小地图与下一层。固定练习层（种子 20261022，东方庭院），角色阿多尼斯、简单难度。黄色箭头沿可走的路指向下一个目标；宝箱和武器箱由教程放在身边，第一级经验不够时补满。练习局不存档、不计分、不消耗花园补给，生命归零时回满而不是结束。卡片在左上角，战斗中 4 秒后折叠成标题
  - 结束页列出全部按键，可以直接「开始正式冒险」（进选角）或「回到画廊」。教程卡片上的「跳过」、暂停页的「退出教程」都算跳过
- 暂停页（游戏中按 Esc）：左侧菜单（继续游戏、游戏说明、图鉴、设置、返回主页），右侧是本局状态：层数与画风、已清房间、击杀、用时、生命护甲等级、各项属性、元素、武器、法术、宠物、加成。返回主页会自动存档

## 操作

WASD 移动，鼠标瞄准，按住左键射击，空格冲刺（冲刺期间无敌），Q / 滚轮换枪，E / 右键双持（两把枪同时开火），F 交互附近箱子、水晶、武器和宝物，G 自动射击，Esc 暂停。

## 镜头

- 分辨率 480×270，按整数倍放大，像素大小始终一致
- 生命 5 格、护甲 4 格，左上角只用图标表示，掉落时闪白碎裂，恢复时弹出；武器在左下角，分主武器栏（弹药格、换弹进度）和副武器栏
- 镜头跟随角色，并朝鼠标方向偏移（最多横 46、纵 28 像素），能看到瞄准方向更远处
- 每次开枪镜头会被反向轻推一下；重武器（霰弹、狙击、火箭、激光、剑）额外带一次小幅震屏

## 武器

12 把武器，共 9 种发射方式，所有武器共用一套属性。

| 武器 | 发射方式 | 特点 |
|---|---|---|
| 骑士手枪 | 单发 | 起始武器，稳定 |
| 冲锋枪 | 单发 | 射速极快，散布大 |
| 连弩 | 单发 | 穿透两个敌人 |
| 狙击枪 | 单发 | 高伤害，贯穿一排，带弹道线 |
| 双管霰弹 | 锥形散射 | 近距离，击退强 |
| 激光步枪 | 光束 | 瞬发直线，撞墙可反射 |
| 榴弹炮 | 抛射 | 落到准星位置爆炸 |
| 火箭筒 | 火箭 | 直线飞行，碰到敌人或墙就爆炸 |
| 回旋飞轮 | 回旋 | 飞出再折返，来回都能命中 |
| 电磁枪 | 链电 | 在敌人之间跳跃，不穿墙 |
| 喷火器 | 火焰 | 近距离持续喷火，点燃敌人 |
| 骑士剑 | 近战斩击 | 扇形斩击，能砍掉敌方子弹 |

**弹匣与换弹**：手枪、冲锋枪、连弩、狙击枪、霰弹、榴弹炮、火箭筒、喷火器有弹匣，打空自动换弹，也可以按 R 手动换；收起的副武器会在后台换弹。激光步枪、电磁枪（能量）、骑士剑（近战）、回旋飞轮（回收）不需要换弹。加成「快手」加快换弹，「扩容弹匣」加大弹匣。

**通用加成**：加成只改属性，每种发射方式按自己的方式解释，所以任何加成都适配任何武器。比如"数量 +1"对手枪是多发一颗，对电磁枪是多跳一次，对剑是多斩一刀；"穿透"对激光是撞墙反射，对剑是飞出剑气。

**元素与反应**：火（燃烧）、冰（减速，叠满冻结）、电（感电）。

| 反应 | 效果 |
|---|---|
| 火 + 冰 = 蒸发 | 额外一次等额伤害 |
| 电 + 冻结 = 碎裂 | 双倍伤害，并溅出冰晶 |
| 火 + 电 = 过载 | 小范围爆炸 |

## 法术（吸血鬼幸存者式自动施放）

12 种基础法术：守护之书、圣光领域、天罚雷击、魔导飞弹、回旋飞斧、冰霜新星、飞刀、陨石、毒雾、电弧、剑环、黑洞。每个法术 5 级，满级后带上对应的加成卡即可进化（例如冰霜新星进化为永冬）。最多同时带 4 个。

**融合**：特定的两个法术都升到 3 级时自动融合成一个更强的法术，并空出一个栏位，有融合动画和提示。融合法术不再升级。

| 融合法术 | 配方 | 效果 |
|---|---|---|
| 雷霜风暴 | 冰霜新星 + 天罚雷击 | 冻结身边所有敌人，再降雷击碎（触发碎裂） |
| 万剑归宗 | 守护之书 + 剑环 | 十把飞剑护身，持续射出追踪剑 |
| 瘟疫领域 | 圣光领域 + 毒雾 | 大范围毒性领域，倒下的敌人炸出毒雾 |
| 天陨 | 陨石 + 回旋飞斧 | 一次四颗陨石，落点燃烧 |
| 千刃追踪 | 魔导飞弹 + 飞刀 | 高速连发的追踪飞刀 |
| 雷暴奇点 | 黑洞 + 电弧 | 巨大黑洞吸住敌群，核心不断放电 |

## 宠物

| 宠物 | 作用 |
|---|---|
| 猎犬 | 冲向敌人撕咬 |
| 白鸽 | 振翅风击，大范围吸取宝石，每清一个房间回复 1 点生命 |
| 天鹅 | 贴身环绕，展翅挡掉敌方子弹，撞伤敌人 |
| 小猪 | 跃向敌群，落地造成范围伤害与击退 |
| 奶牛 | 蓄力后直线冲撞，贯穿途经的敌人 |
| 绵羊 | 战斗中羊毛冲击，推开近敌并回复 1 点护甲 |
| 母鸡 | 远程抛蛋，落地爆开造成范围伤害 |
| 白兔 | 快速跳扑，接续第二次踢击 |
| 灵狐 | 甩尾发射狐火，附着火元素并参与元素反应 |

九种各一只，可同时跟随；不会受伤，非战斗时停止主动技能。每只都有两帧待机、四帧移动、三帧出招贴图，配合蓄力、跳跃、转向、收势和入队弹入动画。

宝物房和升级卡可招募新伙伴。等级 2、5、8……的升级水晶保证有一张招募卡，其他等级有 25% 概率；已拥有的种类不会重复出现，全部集齐后改为其他成长选项。延迟拾取水晶仍按水晶上的等级判定。

宠物默认继承 50% 的玩家伤害加成和元素概率。「羁绊」提高继承，「群猎」提高攻击频率；新增「驯兽术」（伤害）、「兽灵领域」（范围）、「野性本能」（暴击）、「回响追击」（额外半伤追击）、「同心协力」（按伙伴数增加宠物伤害）、「兽群守护」（按伙伴数提供格挡，最高 24%）。拥有三只伙伴后可遇到传说「万兽之王」，提高全队宠物伤害与频率。投入宠物加成后，后续宠物加成的抽取权重逐渐提高，最高三倍。

## 敌人

史莱姆、蝙蝠、小野猪（先预警再冲撞）、哥布林法师（射击）、炸弹怪（自爆）、骷髅盾兵（正面免伤）。精英怪带随机词缀：迅捷、坚韧、分裂、弹幕。

**召唤动画**分三拍：地上先描出法阵（外圈顺时针画出、符文依次亮起），接着法阵外圈像加载条一样填满，同时怪物的剪影（白色填充加一像素描边）在光柱里逐行扫描加载，加载边缘有一道亮线；最后法阵收紧、剪影闪白，整波一起破出。破出后各种怪按自己的方式落地：史莱姆从水洼里冒起、蝙蝠俯冲、巨魔从天而降、炸弹怪从一侧滚进来、幽灵在雾里显形、天使沿光柱降下；法师和精英从裂隙走出，精英召唤时还有三道闪电。现身后先站定 0.3 秒再行动，期间不造成接触伤害。召唤点在屏幕外时，屏幕边缘有箭头指向它。

**Boss 登场**约 4 秒：镜头转向召唤点，上下黑边合拢，房间变暗；地上画出双层大圆、六芒星和十二个依次点亮的符文，能量从全屋汇向光柱，闪电劈在阵边，地面越震越厉害；Boss 剪影在光柱中自上而下加载，闪白后破出、落地、咆哮（三道冲击波和光芒），名字横幅出现，血条从空蓄满，咆哮结束后才开始行动，此前无敌。

## 画风

8 种画风：森林遗迹、冰封雪原、黄沙神殿、熔岩深渊、蒸汽工坊、幽魂古堡、东方庭院、文艺复兴宫殿。每局不重复地随机抽 3 种。

每种画风是一份数据：地砖与墙体样式、敌人配色、道具造型、粒子、Boss 名字、音乐调式与音色。贴图全部由代码按数据现场生成，新增画风只需要加一份数据。

森林遗迹的地面由跨格深浅草皮、连接入口的磨损小径与旧石板组成，墙边分布蕨草、花簇、落叶和碎石，中央战斗区域保持疏朗。灰绿苔石墙配藤蔓、根系和裂缝；古树、白桦、苔柱、巨菇簇、开花灌木和倒木六种造型复用原有障碍位置，可破坏树桩与孢子囊也使用对应的森林造型。地面细节按种子生成并烘焙一次，不改变碰撞格、通路或机关区域。

其余九种地图也各有六种场景摆件与独立地面设计：雪原的冰板积雪、沙漠的风蚀沙丘与古砖、熔岩的玄武岩板和火山灰、工坊的检修板与油迹、古堡的磨损石铺与旧毯、庭院的耙沙汀步和落花、宫殿的大理石嵌边与红毯、深海的沉积纹与破碎马赛克、霓虹都市的湿沥青与灯光倒影。细小杂物避开房间中心、门口和连接通道；所有新增地面绘制裁剪在地板范围内，并避开地刺格和锯片完整轨道。新增摆件只替换原有障碍位置的外观。

## 像素美术

- 统一使用 Endesga 32 调色板，精灵带自动明暗和 1 像素描边
- 光照：整层先压暗，玩家、火把、子弹、爆炸各自补光；光圈是分级的像素色环。特效、伤害数字和光标画在光照层之上，不会被压暗
- 所有界面都是像素化的：中文用开源像素字体 Fusion Pixel 12px，数字和英文用 Press Start 2P 8px，文字先栅格化成像素图再整数倍放大
- 界面风格参考 ACHROMA：近黑面板、1 像素亮边、红色标签、红色菱形光标，标题带色差故障效果

## 打击感

- 卡帧：暴击 25ms，精英 80ms；击杀 Boss 时慢动作
- 开枪：枪口火光、后坐力、镜头反推、光照闪烁
- 敌人受击：白闪、击退、压扁消散
- 伤害数字：普通伤害用小号数字，暴击用大号黄字
- 连杀：音效音调逐级升高，右侧显示连击数

## 音效

用 Tone.js 实时合成，不用方波和 8-bit 琶音，没有任何音频采样。总线上挂压缩器和限幅器。

音乐分场合：
- 画廊大厅、冒险菜单、结算页：舒缓的主题曲（D 小调里拉琴和玻璃旋律）
- 地牢里走动、房间清空后：本层画风的舒缓层（铺底和稀疏的旋律）
- 关门开打：切到本层的战斗层，和舒缓层同一走带同一拍速，节拍玩法的拍子不断。鼓组每十六分音符推进，FM 贝斯奔马律，铜管式短和弦，本层乐器在乐句后半段奏主题；鼓型按画风来（太鼓、四踩、金属敲击、轻打击）
- 尸潮和 Boss：战斗层再加合唱、通鼓、每四小节的镲和 FM 主旋律
- 清房后战斗层在清场号角下淡出，几秒后舒缓层回来；暂停时音乐变闷；死亡和通关时关卡音乐淡出，接回主题曲

交互音效覆盖：所有界面按钮的点击和悬停（大厅、小游戏里也有，返回类按钮音更低），关门、开门、经验宝石吸取和整片吸回、捡枪和换下的枪落地、宝箱、回血、护甲碎裂和回复、最后一颗心的心跳、敌人开火和蓄力、陷阱预警和触发、破盾和碎冰、木箱、下楼、楼层开场、技能、死亡、通关，以及花园、厨房、委托、钓鱼、修复和发现的各个动作。

## 调试参数

- `?seed=42&styles=castle,forest,volcano`：指定种子和画风顺序
