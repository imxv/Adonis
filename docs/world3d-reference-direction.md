## 对照与迭代顺序

1. 锁定视角：记录玩家眼高、FOV、相机位置和朝向；给每张参考对应一个固定验收机位。先对齐地平线、主体占比、路径曲线、山体/建筑/树冠轮廓与遮挡关系。
2. 大形与比例：真实可绕行、可近看的建筑和地形；中远景也有完整轮廓和布局，拒绝画布贴图代替可探索世界。先通过结构对照再添加微细节。
3. 颜色与明暗：同机位对照天空、石材、草木、浅水、深水的主色和明度关系；暖亮面、冷影和接触阴影建立层次；不用整体雾或降低饱和度掩盖问题。
4. 材质与模型：石材接缝/侵蚀/雕饰，非重复的树干分枝与树冠，岩石宏观裂隙—中尺度层理—表面细节；避免均匀噪点、一样的树/岩堆和细枝几何数量堆砌。
5. 水与瀑布：深浅颜色、岸边湿痕、折射与角度反射、动态波纹和局部泡沫；瀑布分层水片/水束/落点白沫/水雾/涟漪，不能是发光白条或不透明蓝平面。
6. 近中远景密度：同一建筑模型允许合理模块复用，但每一处组合/破损/材质/植被关联有差异，不能显出复制粘贴。远景通过有效LOD和材质细节保持轮廓与色彩，而非把近景高面数无限复制。
7. 逐轮交图：参考、当前实景、差异清单、修改项、尚存差异；原机位前后对照。每轮先解决影响最大的2–3项，不以次数或构建成功代替品质。
8. 最终确认：实际行走、环绕/近看/远看、水体动态及输入返回；桌面与手机档分别记录画布/帧率/几何/资源，手机模拟不冒充真机。实景达到新的视觉目标后才重新进入发布阶段。
