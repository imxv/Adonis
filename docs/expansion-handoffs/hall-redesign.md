## 本轮改动

- `src/hub/gallery.ts`：以根生成的 `public/hub/hall-v2.png`（1672×941）作为完整绘景，移除旧浅绿色矢量大厅。背景不叠大面积蒙层；只有少量烛光、微粒、地面抵达点与入口小标签。
- `src/hub/gallery.css`：场景铺满视口；标题、资源放在角落，底部改为单排紧凑快捷入口，按钮最小高度44 CSS px。原上下大导航卡片移除，使用项目像素字体与深紫、旧金配色。
- 阿多尼斯直接复用 `ADONIS_A/B` + `Grid` 生成两帧精灵，按整数源像素放大，屏幕高度约60–80px；保留脚影与少量步行动作。
- 世界尺寸与热区全部改为新图1672×941。左画 `(375,125,270,440)`，抵达点 `(500,610)`；右画 `(1025,115,275,450)`，抵达点 `(1150,610)`；花园 `(28,500,360,360)`，抵达点 `(420,760)`；收藏 `(1400,330,272,550)`，抵达点 `(1310,760)`。
- 可走地面限制在中央铺装：y600–870，两侧随前景植栽收窄。小视口通过相机跟随保留人物尺度，快捷入口始终作为可见替代路径。

## 保留的契约

`GalleryAction / GalleryState / GalleryOptions / GalleryHandle` 对外形状未变；`mountGallery` 的 `refresh / pause / dispose / onAction` 继续沿用。保留键盘移动、点击/拖动走动、到达画框后自动进入、F/Enter近距离交互及650ms防重复触发。

暂停清输入、pointer capture、动画帧；恢复重新测量并恢复聚焦。释放时移除事件监听/ResizeObserver、取消动画、释放本实例画布和人物画布，解除图片加载回调。`pxText` 返回的共享缓存画布不清空，只清本地引用。

不修改controller、meta、world3d、ui.ts。未触碰历史 `tools/playtest.js` 和 `output/`。未写UI单元测试。
