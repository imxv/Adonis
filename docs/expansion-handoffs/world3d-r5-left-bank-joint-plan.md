### 传播与封口必须局部化

当前 `createBoundaryHeightField` 以136个点做全域 mean-value coordinates；内部一般点会受所有边界样本影响。`foundationY=min(十个outerFoot,池床下限-1.4)-.75`，随后顶面最低被夹到 `foundationY+1`。普通回调替换会使全局 foundation **2.139612851→.0765m**，牵动整块底面和顶面夹值。因此不能直接将19点接到当前 C 回调。

唯一提议是 C 将东南区单独切分，保留旧全局 foundation=2.139612851 和域外原始场；局部支撑多边形为 `[[14.5,-5.6],[19.7,-5.6],[20.75,-1.2],[19.8,3.5],[16,5.65],[13.95,3]]`，并取其与现有 C 实体的交集（C原体只到Z3.5）。局部同XZ顶/底柱同步移动，以 D新面−.18 为**混合目标**；它仅在最终权重为1处构成顶面上限，不能称为全作用域硬上限。向边界零权重返回，重建局部侧面与底面封口，焊接边界、法线并另行读回真实接触。全局池环/MVC及域外网格保持原值。

**局部底面不要求仍在全局 foundation 高度上。** 预览 C clone 最低Y由2.139613降到−1.362458，保留的是全局参数，不是每个底顶点。局部顶/底一起移动仅保留柱厚，不能证明最终封闭流形；分区边界闭合和真实地面接触必须由 C 实现后验证。预览的 `cDelta` 是联合目标包络的几何替身，与19点简单回调重建不等价。当前 `closureAccepted=false`。

### 单一权重接口：04b-contract-1

可复用 D helper：[grove-bank-patch.mjs](../../src/world3d/evidence/reference-v3/r5/joint-bank-plan/grove-bank-patch.mjs)；[接口与未来接入伪码](../../src/world3d/evidence/reference-v3/r5/joint-bank-plan/grove-bank-patch.types.source.txt)。接口 revision 为 `r5-grove-bank-patch-04b-contract-1`，形体仍是04b，C支撑多边形及D总域均不扩。此模块尚未接入产品或 C options。

```ts
groveBankPatch = {
  revision, shapeRevision, baselineRevision,
  domainXZ, rockInsetM: .18,
  baselineTerrainHeight(x, z),
  sample(x, z): { terrainY, weight }
}
```

由 D 构造一次并交给 C。`baselineTerrainHeight` 是冻结873c/a1e7/20ad候选的**未应用联合patch、但已完成旧路/水/瀑布overlay的最终解析回调**。C 构造原体时只能用此旧基场查询全部136点、10个outerFoot和foundation；有patch时即使外部 `terrainHeight` 已为D新目标，也不得把它用于原MVC。缺省 `groveBankPatch` 时走原有构造分支，完全旧行为；当前只验证helper无patch位移为0，产品C缺省回归需未来接入后验收。

`sample.terrainY = profile.detail(X,Z,baselineTerrainHeight(X,Z)).height`，是已完成所有D形体混合和路/水保护的**最终解析目标**，不是未混合平台高度，也不是D三角面射线高度。C直接消费，不再对它与旧D高度做lerp；改成实际D网格射线采样会另成候选。

唯一岩体位移权重为 `sample.weight = detail.weight * cEdgeFade`。其中 `detail.weight` 已含台面/连接/坡脚支撑、端点返回、路水guard；`cEdgeFade = 0` 于C域边界及域外，域内距边界至少.35m时为1，内侧.35m带中为 `1-smoothstep(-.35,0,signedDistance)`。C不得再乘边缘、路水guard或自己的局部blend。

令 `T0(X,Z)` 为未变形原C的顶面上包络：在共享边切分、生成新节点时，从原C三角面求该XZ的最高顶面Y；不得取D高度、`terrainY-.24`、全局foundation或已移动的C点替代。C保留原坐标/原顶场，对每个同XZ柱只执行：

```ts
const { terrainY, weight } = patch.sample(x, z);
const deltaY = Math.min(0, terrainY - patch.rockInsetM - T0(x, z)) * weight;
newY = originalY + deltaY; // 顶/底/侧共享节点都加同一个delta，仅一次
```

helper 已导出 `groveBankColumnDelta(patch,x,z,T0)`，C可直接使用该函数避免重写混合。`weight=1` 时新顶=`min(T0,terrainY-.18)`；`0<weight<1` 时新顶=`(1-weight)*T0+weight*min(T0,terrainY-.18)`，**允许高于terrainY−.18，甚至高于D面**；这是冻结04b的过渡规则，不承诺该带有.18m净退让。`weight=0`时该柱完全保留。位移只下移，不抬高旧C顶；严禁重复执行到已变形顶上。

实测旧C反例 `[16.7,-3]`：T0=5.667677、D目标4.658103、混合目标4.478103、最终权重.176305，新顶5.457949，比混合目标高.979846m。它证明原“全域目标上限”表述不成立；把过渡区改成硬封顶会改变当前形体，需要另立候选。

原 `addMass` 只有 scalar `bottomY`。因此正式C实现应先按旧基场构造原体，再在局部分区切分共享边并对顶/底/侧做上述后处理，不能把foundation换成局部函数或改全局callback。C的最终接触元数据必须来自变形后的真实网格读回，原136点/MVC/outerFoot构造输入保留，19点减.24列不能充当这份读回。

原隔离预览以局部细分后、1e−6米XZ键上的旧顶点最大Y近似柱顶；正式C共享节点应求原三角面顶包络。当前新增helper只固定D目标和位移代数，不宣称未来C不同切分节点已与旧照片逐顶点等价。正式网格须重新检查封口、接地和观感。

### 外围正式实现的两项有限要求

独立视觉复审只认可“两级宽台”的形体方向。两处2×2核心及其当前目标平面保留，外围04b轮廓不能原样作为最终冻结版；作用域和路面安全域不扩。

1. 上下台缘长短错开，并有一处明确退让口，避免平行、等厚的人工阶梯感。
2. 在高路壁墙脚或台面外围形成一处斜向大转折，分成不同朝向的大面；高路面硬域保持旧值，不延续长竖槽壁，也不添加细碎噪声掩盖。

涉及高度/轮廓的改动由 D 在同一域内更新解析目标并更换shape/patch revision、重新出有限接触表和预览后交 C；当前contract-1只精确描述已看过的04b，不暗含这两项几何已经完成。C可按新版目标重组共享拓扑和修正材质映射，但不得对`sample.terrainY`或最终weight再加独立混合。局部直壁纵向纹理拉伸也须正式修正。形体方向认可不等同于接口接入、产品、封口或美术放行。
