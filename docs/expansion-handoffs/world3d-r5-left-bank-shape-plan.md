## C callback 保护

建议域和 C 当前 outer 接地边界相交的折线为：

```text
[18.6721,-6] → [18.415,-2.44] → [15.1,3.5] → [13,3.3546]
```

C 以不大于 .6m 站距采 `terrainHeight-.24`，并以 mean-value coordinates 向内部传播；改变任一边界采样可能改变整片 C 岸体。因此第一切片的形体 mask 在 C outer 内部、实际边界及保留接地带上必须严格为零，全部 callback 原值有限读回相等后再回拍。若效果确实要求移动该边界，先将准确变更点/幅度交根协调 C，不暗改 callback 或复制一套 C 形体数据。

冻结 `walk.mural [10,4.5,8]→[14,4.5,5]` 中心线外 1.7m 的铺石承托；邻近主潭边 `[16,18]→[20,0]→[28,-11]` 的水内高度完全不动。C 桥肩采样约 z=-16..-18，不在本域。

## 候选大形

只替换局部宽坡的低频剖面，不继续向旧鼓坡叠土：

1. 一条沿 C 外缘向主潭斜出的不规则主岸肩，陆侧接点不变，中段约 Y3–4m；不拉等高整圈长墙。
2. 仅两处错位、至少 2m 宽的下层岩台，初值约 Y1.0–1.6m；各约1–2m短落差与1.5–3m水平过渡。
3. 原有水域 upper ceiling、channel carve、frozen cut 与精确路面承托最后执行；池内和 outlet 不因造型抬高。

可复用 D `polygon/signedDistance/smooth/mix`，在局部域用 `mix(oldHeight, localAbsoluteProfile, mask)` 组织剖面；仅 Math.max 会保留旧连续鼓坡。高度和轮廓是首轮候选，需固定 waterfall 和近侧面的前后对照，不能以数值合法代替形体判断。
