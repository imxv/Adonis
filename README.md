# Adonis · 画中轮回

网页上的 2D 像素射击肉鸽。阿多尼斯一次次死去，又一次次重生：每一层地牢是随机抽到的一种画风，最后一层永远是那头撞死他的野猪。

- 元气骑士式地牢：异形房间加走廊，进门锁门，清完怪才开门；房间里有掩体、地刺、锯片和每种画风专属的雕像、树木、烛台等障碍
- Hi-Fi Rush 式节奏近战：整座地牢踩着音乐的拍子，近战武器有三四段连招，踩拍出招伤害更高，终结技踩拍打出强化版；D→SS 风格评级决定得分倍率，每个房间清完盖章评分
- 吸血鬼幸存者式成长：经验宝石、12 种自动法术和进化，两个法术到 3 级自动融合成 6 种融合法术之一，尸潮房
- 原神式元素系统：火水雷冰风岩草七种元素的附着、反应与克制，各画风的怪带当地元素，精英带元素护盾，7 把元素武器专打反应
- 24 把武器（5 把近战带连段与终结技），枪械有弹匣和换弹，所有加成通用于任何武器；法术是辅助，武器是主力；3 只宠物；17 种怪物，其中 10 种是各画风的专属怪，各有出场动画和音效
- 11 个 Boss：10 种画风各有一位按副标题设计的守卫（4 个姿态加二阶段形态，蓄力报招、起跳砸地、专属技能和弹幕形状、碎裂死亡），第五层是那头野猪；清房和击杀 Boss 时有子弹时间
- 五层地牢，从 10 种画风里随机抽取，美术全部由代码生成，音效运行时合成，不使用任何外部图片和音频素材
- 主菜单是一幅会动的画（大理石大卫与银莲花月亮），带存档继续、全服排行榜（连不上时用本机榜）、游戏说明、图鉴（从游戏数据自动生成）和设置；游戏中按 Esc 查看本局完整状态

## 运行

```bash
npm install
npm run dev
```

打开 http://127.0.0.1:5173 即可。`npm run build` 会打包出可直接部署的静态网页 `dist/`。

## 操作

| 按键 | 作用 |
|---|---|
| WASD | 移动 |
| 鼠标 | 瞄准，按住左键射击；近战武器踩着拍子按下更强 |
| 空格 | 冲刺（冲刺期间无敌）；拿近战武器踩拍冲刺会炸出冲击波 |
| Q / 滚轮 | 换枪 |
| R | 换弹（打空也会自动换） |
| E / 右键 | 双持，两把枪同时开火 |
| F | 自动射击 |
| Esc | 暂停；在三选一面板里是跳过 |

## 调试参数

| 参数 | 作用 |
|---|---|
| `?seed=42&styles=castle,forest,volcano` | 指定随机种子和画风顺序 |
| `?diff=easy` / `?diff=hard` | 难度 |
| `?god=1` | 无敌 |
| `?room=boss` | 直接从 Boss 房开始 |
| `?weapon=rocket` | 指定初始武器 |
| `?light=0` | 关闭光照 |

## 技术

Phaser 3.90、TypeScript、Vite，音频用 Tone.js。设计文档见 [docs/spec.md](docs/spec.md)。

`tools/playtest.js` 是开发用的自动试玩脚本：在开发服务器页面的控制台里执行 `const pt = await import('/tools/playtest.js'); await pt.start();`，之后 `pt.play(600)` 让机器人自动打 600 帧。
